# R1.4-C0.1｜PCI 与电源井接口合同

2026-10-12。起点 `027bd7c9ce3fe9fe5615186aa864484752eb1986`；本地同 main 研发，无分支/工作树/推送。证据等级 **SOURCE-STATIC**；结果仍为 **DEPENDENCY_CLOSURE_BLOCKED / RUNTIME_NO_GO**。

## 实质增量

复用 C0 的固定版本、源字节及探测路径，不重跑旧 VBL、构建、发行包或硬件调查。本轮实际审查固定 FreeBSD14.3 的 make 规则、七组生成接口输入、PCI/DMA 提供者，以及 power timeout 到 probe 的传播。详细行号、Git blob 和合同在 [工程目录](../research/independent-i915/c01/README.md)。

三个新结论直接改变移植要求：

1. 46A6 / ADL-P 的 display13 选择 **xelpd_power_wells**，结合 ICL PW1。不能用 Tiger Lake 的表或文件名裁剪代替平台判断。
2. `hsw_wait_for_power_well_enable` 超时只日志/WARN，经过 void enable 链没有错误返回到 probe；外层仍设 `hw_enabled=true`。这不是硬件上电成功证明。独立接口必须检查 request/state/fuse 的后置条件，再更新可用状态和资源所有权。
3. XNU PM 消费逻辑把负的 setPowerState 返回值当作完成确认，不能用 Linux errno 传播供电失败。需要独立故障状态、阻止显示发布、有限时恢复/退出和确认策略；目前这些仅为未实现合同。
