# R0.7 — Native NVAccel build qualification

## Scope

The workflow [HONOR R0.7 NVAccel build gate](../.github/workflows/nvaccel-build-gate.yml) is **manual-only** and executes on GitHub-hosted `macos-15-intel` with a 20-minute timeout. It does not access the HONOR laptop or write any Windows, EFI, BIOS, or disk settings.

1. Compile `tests/kernel_header_smoke.cpp` as a **macOS kernel-mode x86_64 object**, without linking or running a kext.
2. Shallow-fetch and verify NullMoth Git commit `0960b2ef5dbc4a573056d4c8e042a5bd2e15d651`. Compare the seven known Git blob hashes using the previously tested [integrity verifier](../scripts/verify_pinned_source.py).
3. Shallow-fetch NVIDIA `open-gpu-kernel-modules` at the exact commit `e4a5faa2567f28c8eabe0ebb6422b6d0abcf37eb`, the peeled commit of the signed tag `610.57.04`.
4. Check for `src/nvidia/_out/Darwin_x86_64/compile_cmds.sh`, which the upstream NullMoth `build/accel_build.sh` actually consumes.
5. If **and only if** this generated metadata exists and `mode=build`, invoke upstream `build/accel_build.sh` to attempt an unmodified NVAccel build. No installer, kext loader, code signing or EFI tooling is run.

## How to run

Open [GitHub Actions](https://github.com/Jakiewbe/honor-hackintosh-lab/actions/workflows/nvaccel-build-gate.yml). Select **Run workflow → main → prerequisites**. Only the user can trigger this manually. Standard GitHub-hosted macOS runner usage may have billing implications: check GitHub Actions usage/billing settings before starting.

If it fails, share the URL. Detailed diagnostics are also attached under the action artifact `honor-r07-diagnostic-logs`, containing **text files only** and retained for 7 days.

`build` mode is intended only after the generated Darwin RM metadata becomes available: with the presently published NVIDIA Linux source alone, it is expected to stop with a clear **BLOCKED** error and **not** invoke the compiler for NVAccel.

## Interpretation

- `KERNEL_HEADER_OBJECT_COMPILE_PASS`: basic SDK compatibility probe passed. **Not a driver build.**
- `PINNED_SOURCE_TREES_VERIFIED`: two pinned source trees checked out and seven NullMoth blobs verified.
- `BLOCKED: ... Darwin_x86_64/compile_cmds.sh`: known missing generated compiler metadata, not evidence against RTX 2050.
- `R07_PREREQUISITE_CHECK_FINISHED`: end of prerequisites check; **does not mean NVAccel was compiled**.
- `NVACCEL_NATIVE_BUILD_FINISHED`: compilation/link stage executed and returned success, but still requires manual checks and hardware testing.

NVIDIA's public `open-gpu-kernel-modules` repository is primarily distributed as **Linux** kernel driver source. Its published `610.57.04` tag does not include the pre-generated macOS/Darwin compiler metadata expected by NullMoth's macOS build script. Reconstructing those arguments is further research work; do **not** substitute random Linux compiler flags or run an unofficial installer.

The source code is covered by its original license. The workflow downloads it ephemerally; this repository does not redistribute vendor source or GPU firmware. No compiled kext binary is uploaded as an artifact.
