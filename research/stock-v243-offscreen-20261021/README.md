# RTX 2050 离屏 Metal 验收程序候选

目标是第一次真实设备验证时有可读、可拒绝、可复算的程序。
当前只允许编译，设备 NO-GO。CI 只调用编译器和静态工具，不运行该程序，不上传二进制。
本程序不安装、加载或卸载驱动，不测试系统睡眠，不改变显示所有权。

代码只有收到显式执行开关和已知非零 registry ID 才调用 Metal/IOKit。
真正执行时，枚举/匹配本身可能启动设备；开关不是设备准入授权，不能绕过项目 NO-GO。
实际授权还需指定隔离设备/系统版本、恢复方案和允许的运行阶段。

程序的受测链：

1. MTLDevice registryID 必须与输入逐字相等，且 IORegistry 向上的 IOPCIDevice 为 10DE:25A9；不得误选 Intel 或按设备名称猜测。
2. 64 个 uint32 计算结果逐项与 CPU 预期比较，输出初始值与预期不同。
3. 私有 RGBA8 纹理上提交一个真实三角形绘制；先清品红，再画全屏绿色。
4. 编码 blit 到 shared buffer，等待命令完成后按 256 字节行距比较全部64个像素；不把非空输出或 clear 当 draw 成功。
5. 无效着色器必须编译失败且带 NSError。这只验证编译错误传递，不冒充 GPU 异步故障注入。
6. 每条命令最多等待10秒；超时/状态错误/像素错误立即非零并停止新提交。

只有全部完成才输出 APP_TEST_PASS。日志同时声明：内核关闭、PM、驱动 teardown 未测试。
API完成、正确结果和设备绑定仍须结合固定驱动/NVK的实际命令提交证据，
不能仅凭本程序日志断言物理 GPU 已执行，或保证失败后可安全热卸载。
超时后仍在途的 GPU 工作/进程退出清理是待审查项；当前程序不具备放行这类设备实验的资格。

基线：公开 Metal/IOKit API、macOS SDK15.5、x86_64、部署参数15.5；不依赖 Vulkan SDK、现成驱动二进制或上游安装器。
新原生编译尚未执行。运行、实际计算、真实渲染、像素、错误与退出均未验证。
